# Auotmatic-roofing-system
As we know about 70 percentage of our country’s revenue comes from agriculture. But during heavy
rainfalls, the farmers face a lot of problems because their cultivated crops get washed off or destroyed
Which reduces the plant growth in turn reduces yield. As human beings, we cannot control the natural phenomenon such as rain, moisture, etc. Some
of the measures are taken against this environmental hazard but they are performed manually. Here comes the need for automation. So to avoid this
problem this project is designed, which helps in protecting the crops from heavy rainfall and saving that rainwater to use for other purposes. In
this system, an automatic roof is used which works by taking the signals from the rain sensor and soil
moisture sensors and covers the whole field to protect it from heavy rains. Whenever there is rainfall the rain sensor gets activated. The soil moisture
sensor is used to check the water content in the soil.Whenever there is rain, the rain sensor gets on
and the Sensor output value below a threshold indicates heavy rain, while the sensor output value above the threshold value indicates light rain or no
rain. If is a heavy rain fall then the BO motor starts which opens the roof automatically to close the field
using a polythene sheet. Here we will be using a Liion batteries for power supply. The roof will be kept on a slope so that the water can be collected
in a container for feeding animals, washing, cooking, etc., and can also be reused to sprinkle it back.
